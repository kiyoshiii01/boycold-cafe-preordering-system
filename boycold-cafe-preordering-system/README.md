# Boycold Cafe - GitHub Pages Version

This is the static HTML version of the Boycold Cafe Pre-Ordering System.

## Stack
- HTML
- Inline CSS per page (`<style>`)
- Inline JavaScript per page (`<script>`)
- localStorage for demo/frontend data

## GitHub Pages
Upload the contents of this folder to a GitHub repository and enable GitHub Pages.

`index.html` is the main entry page.

## Demo Login
The original mock accounts were preserved:

- staff@boycold.com
- sales@boycold.com
- inventory@boycold.com
- cashier@boycold.com

For this static version, any non-empty password is accepted for those demo accounts.

## Important
This version does not use PHP, MySQL, XAMPP, or a backend server. localStorage is only suitable for a frontend/demo version and is not secure authentication or a real database.
